# Content Library

Content Library items may be input documents, generation instructions,
single-evaluation instructions, pairwise-evaluation instructions, evaluation
criteria, Combine instructions, template fragments, output documents, or
read-only run logs. Content bodies can be large, so list first and read only
the requested item or bounded page.

Creating or updating content requires a read_write API key and explicit user
confirmation in the tool arguments. Run logs are read-only. Never expose
secrets found inside content, tool results, provider keys, database keys, or
API credentials.
