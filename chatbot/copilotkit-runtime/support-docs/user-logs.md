# User Log Guide

User run logs are encrypted user-side logs. They are different from backend server logs and admin logs.

The default website view reads EVENT logs. DETAIL logs are available when the user asks for full detail or when debugging requires payload-level information.

The assistant may read only the logged-in user's run logs through ACM's run log APIs.
